# AGENTS.md — working rules for this repo

This repo is a public field guide for [FastPress Labs](https://github.com/fastpresspages). It is prose, not code, but the same honesty rules apply.

## Read first

- [README.md](README.md)
- [GOALS.md](GOALS.md)
- [docs/ideas.md](docs/ideas.md)
- [docs/launch-plan.md](docs/launch-plan.md)

## Non-negotiables

1. **No invented numbers.** Every metric needs a date and a source. If there is no source, remove the number or label it as a target.
2. **No fake proof.** No invented testimonials, customers, partnerships, revenue, followers or "users".
3. **No spam tactics.** No mass email, bought lists, engagement pods, upvote requests, fake accounts or scraped addresses.
4. **No tracking.** Do not add analytics, pixels or session replay to FastPress Labs pages. Measurement lives in forms and GitHub Insights.
5. **No private data.** Do not publish anyone's email, name, company or private dashboard without explicit permission.
6. **Templates stay templates.** Use `[placeholders]`; do not fill them with a real person's details in a way that looks like a sent message.
7. **Links must work.** Verify every URL you add. Prefer canonical URLs.
8. **Dates matter.** When a doc describes a live result, include the date and the report link.

## Editing conventions

- Plain Markdown, short paragraphs, sentence case headings.
- Tables are fine for comparisons; keep them narrow enough to read on a phone.
- Use "we" for FastPress Labs, "I" only in first-person templates.
- British or American spelling is fine; be consistent within a file.
- Do not use em dashes as a substitute for structure. Short sentences are better.
- Keep the tone direct. No hype, no "10x", no "revolutionary".

## When adding an idea

- Put it in [docs/ideas.md](docs/ideas.md) with effort, distribution and a "do not" line.
- Mark it as a candidate, not a commitment.
- If it needs a paid API or a paid directory, say so.

## When adding a template

- Put it in [docs/outreach-emails.md](docs/outreach-emails.md) or [docs/social-copy.md](docs/social-copy.md).
- Include the rule that makes it honest, not just the copy.
- Do not add a fake deadline, fake scarcity or fake compliment.

## When updating goals

- Edit [GOALS.md](GOALS.md) with a date and a source.
- Never change a baseline to make progress look better.
- If a target is missed, say so. The miss is data.

## Verification before a PR

- [ ] Every relative link resolves.
- [ ] Every external link opens and is the intended page.
- [ ] No unsourced number or unverified claim.
- [ ] No private contact information.
- [ ] The README index still matches the files.
- [ ] The change does not add tracking or a paid placement.
